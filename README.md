# WIN Tax & Bookkeeping Academy — Course Preview

Interactive client preview build of the WIN Tax & Bookkeeping Academy course framework.

- Beginner tier only
- Browse every module/lesson, watch the slide + video-script placeholders, view mock source documents, and take the interactive quizzes with live scoring

This is a preview build for client review — not the final learner-facing hosting platform.

## Beginner Tier — narrated course (`/beginner/`)

The full Beginner Tier (Start Here + 4 modules × 4 lessons) following Deja Marsh, built from the approved "Beginner Course — Full Build" script:

- Every lesson is narrated (AI voice matched to the HeyGen presenter) with follow-along visuals: W-2 / 1099-NEC boxes and key ideas light up as they're explained, with captions and a read-along transcript
- Practice checks, WIN Reviews, Capstone and Final Assessment with the builder answer keys
- Progress is saved in the learner's browser

Open it at `/beginner/` on GitHub Pages. Narration clips live in `beginner/voice/` (one MP3 per script line). The guide in the video frame is a placeholder until the HeyGen avatar clips are rendered.
